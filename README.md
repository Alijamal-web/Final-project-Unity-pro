

# Unity Racing Game

## About the Project

This project is a 3D racing game developed using Unity and C#. The project was created to gain practical experience in game development, programming, vehicle physics, and AI behavior.

The game features a player-controlled car, an AI-controlled vehicle, a racing track, a main menu, and a finish-line system.

## Features

- **Player-Controlled Vehicle:** A car controlled by the player.
- **AI-Controlled Vehicle:** An AI car that moves around the track independently.
- **Vehicle Physics:** Physics-based vehicle movement and control.
- **Racing Track:** A 3D environment designed for racing gameplay.
- **Main Menu:** An interactive menu for navigating the game.
- **Finish-Line System:** A system designed to detect race completion.

## Technologies Used

- Unity
- C#
- Git
- GitHub

## How to Run

1. Download the game ZIP file from the [Releases](https://github.com/Alijamal-web/Final-project-Unity-pro/releases) section.
2. Extract all files into a folder.
3. Keep all extracted files and folders together.
4. Run `Final project Unity pro.exe` to start the game.
